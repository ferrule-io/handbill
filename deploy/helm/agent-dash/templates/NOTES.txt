{{- if .Values.ingress.enabled }}
  App UI & MCP:  {{ .Values.app.origin }}
  Hosted Sites:  https://<site-id>.{{ .Values.app.sitesDomain }}

  DNS Configuration:
  Ensure the following DNS records point to your ingress controller or load balancer:
    - {{ include "agent-dash.appHost" . }}
    - *.{{ .Values.app.sitesDomain }}

  Wildcard TLS:
  Because each site is served from a random subdomain (<site-id>.{{ .Values.app.sitesDomain }}),
  a wildcard certificate (*.{{ .Values.app.sitesDomain }}) is required.
  If using cert-manager, wildcard certificates require a DNS-01 challenge issuer (HTTP-01 cannot issue wildcards).
{{- else }}
  Get the application URL by running these commands:
    export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "agent-dash.name" . }},app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=app" -o jsonpath="{.items[0].metadata.name}")
    kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "agent-dash.fullname" . }} 8080:{{ .Values.service.port }}

  Open the App UI at:
    http://127.0.0.1:8080 (or your configured APP_ORIGIN: {{ .Values.app.origin }})

  Without the chart's Ingress, ensure both:
    1. {{ include "agent-dash.appHost" . }}
    2. *.{{ .Values.app.sitesDomain }}
  are routed to the Service: {{ include "agent-dash.fullname" . }} on port {{ .Values.service.port }} (via your custom Ingress, Gateway API, or reverse proxy / tunnel).
{{- end }}
